<h2 align="center">👾</h2> 

<p align="center">Мы создали интеллектуальный помощник в социальной сети ВКонтакте для того, чтобы взять на себя рутину планирования и сделать процесс обучения более осознанным и эффективным. Встроенный чат с искусственным интеллектом понимает естественный язык. Достаточно лишь написать и бот сам извлечёт нужную информацию, предложит подтвердить действие и выполнит его. AI также умеет кратко пересказывать длинные конспекты и показывать ближайшие события по запросу. </p> 

<h2 align="center">👾</h2> 

<p align="center">В отличие от обычных календарей, наш бот не просто хранит расписание, а активно взаимодействует со студентом: с помощью загруженных материалов он создаёт персонализированную базу для обучения. Все данные автоматически сохраняются в Google Drive в отдельной папке. В любой момент можно найти нужную заметку по названию или дате создания, а также просмотреть все конспекты по выбранному предмету</p> 

<h2 align="center">👾</h2> 

<p align="center">Для каждого конспекта можно поставить напоминание в Google Calendar с указанием определённой даты и времени. Команда «Что скоро?» показывает все ближайшие события из календаря на неделю вперёд. Так вы не пропустите дедлайн и всегда будете знать, что нужно повторить.</p>

## 🟪 Анализ требований и ограничений

<br>

| Требование |	Влияние на архитектуру |
| ------------- | ------------- |
| **Работа в VK (бот для социальной сети)** |	Использование VK API и VK Bot Long Poll, отсутствие необходимости в веб-сервере для основного функционала (только для OAuth). |
| **Интеграция с Google Drive и Google Calendar**	| Паттерн "Адаптер", представляющий собой отдельные классы DriveAPI и CalendarAPI, OAuth-авторизация через отдельный Flask-сервер для получения токенов. |
| **Использование AI (OpenAI-совместимые модели)** |	Слой абстракции, который позволит поддерживать любой API с интерфейсом OpenAI (базовый URL, ключ, модель задаются через переменные окружения), возможность смены модели без изменения кода. |
| **Хранение пользовательских данных** |	Хранение: состояние диалога, список предметов, выбранный предмет, временные данные, Google-токены, история AI-чата, персонаж AI. |
| **Понятный интерфейс с кнопками** |	Отдельный модуль со всеми клавиатурами, состояния пользователя управляются через БД, payload-кнопки для бесшовной навигации. |
| **Управление конспектами** |	Drive выступает как хранилище файлов в формате Markdown, бот не хранит содержимое конспектов в своей БД, атолько метаданные. |
| **AI-распознавание намерений** |	Наличие JSON-схемы, бот парсит ответ AI и извлекает его, подтверждение действий перед выполнением. |
| **Масштабирование на 1-5 предметов** |	Монолитная модульная архитектура, все модули независимы друг от друга. |
| **Возможность локального запуска и в Colab** |	Все зависимости в одном списке, отсутствие привязки к специфическим серверным технологиям, ОAuth-сервер может быть запущен на любом хосте с публичным URL. |

## 🟪 Обоснование выбора архитектурного стиля

<br>

1. Модульный монолит (Modular Monolith)

Мы выбрали модульный монолит как основной архитектурный стиль по следующим причинам:

- 🟣 Простота разработки и отладки.

- 🟣 Легкость развертывания.

- 🟣 Возможность параллельной работы.

- 🟣 Независимость и заменяемость модулей.

<br>

2. Слоистая архитектура (Layered Architecture)

Для организации кода внутри монолита используется луковая архитектура: 

🦐 Представление или Presentation (Клавиатуры, форматирование сообщений) --> `vk_view.py`
<br><br>
🦐 Контроллер или Controller (Логика обработки сообщений, состояния) --> `bot_controller.py`
<br><br>
🦐 Сервисы или Services (Внешние API, AI, бизнес-логика) --> `ai_helper.py`, `google_services.py`
<br><br>
🦐 Инфраструктура или Infrastructure (БД, OAuth-сервер, работа с токенами) `db.py`, `auth_server.py`

<br>

3. Паттерны проектирования

| Паттерн |	Где применяется? |	Зачем? |
| ------------- | ------------- | ------------- |
| **Адаптер (Adapter)** |	`google_services.py` (DriveAPI, CalendarAPI) |	Единый интерфейс для работы с Google API. |
| **Стратегия (Strategy)** |	`kb_*()` в `vk_view.py` |	Разные типы клавиатур под разные состояния. |
| **Команда (Command)** |	Payload-кнопки (`{'a': 'action', 'v': 'value'}`) |	Универсальный формат для действий пользователя. |
| **Шаблонный метод (Template Method)** |`st_*()` методы в `BotController`|	Единая сигнатура всех обработчиков состояний. |
| **Одиночка (Singleton)** |	`Database` (одно соединение), `client` в `ai_helper.py` |	Гарантирует единственный экземпляр подключения. |
| **Фасад (Facade)** |	`BotController` |	Упрощает взаимодействие между VK, БД, Google API и AI. |

### 👾 Описание потоков данных

  1. Пользователь --> VK API --> BotController: Сообщения и нажатия кнопок.

  2. BotController --> Google Services: Создание/чтение файлов в Drive и событий в Calendar.

  3. BotController --> AI Helper: Генерация ответов и распознавание намерений.

  4. BotController --> DB: Сохранение состояний, предметов, истории диалогов.

  5. Auth Server --> Google OAuth: Получение и обновление токенов доступа.

### 📱 Как начать работу?

1. Перейдите в диалог с нашим ботом ВКонтакте.

2. Отправьте любое сообщение – бот ответит ссылкой для авторизации.

3. Перейдите по ссылке и разрешите доступ к Google Drive и Google Calendar.

4. Готово! Вы в главном меню.

<br>

### 📚 Работа конспектами

- 🟣 Добавить предмет:<br><br>
Нажмите «Предметы», «+ Добавить предмет», а затем введите название необходимой дисциплины.

- 🟣 Выбрать предмет: <br><br>
Нажмите на название предмета в списке.

- 🟣 Создать конспект: <br><br>
Выберите предмет, нажмите «Написать конспект», введите соответствующие название и текст, бот сохранит файл в Google Drive и предложит поставить напоминание.

- 🟣 Найти конспект: <br><br>
Выберите предмет, нажмите «Поиск / Просмотр», ищите конспект в списке по названию, дате или смотрите все.

### ⏰ Напоминания

- 🟣 После создания конспекта:<br><br>
Бот спросит: «Поставить напоминание в календаре?» — нажмите «Да» и выберите дату и время.

- 🟣 Просмотр ближайших событий:<br><br>
Нажмите «Что скоро?» в главном меню – бот покажет все напоминания на ближайшую неделю.

### 🤖 ИИ-чат

Самый удобный способ взаимодействия. Просто пишите обычными фразами:

| Что мне сказать? |	Что сделает бот? |	
| ------------- | ------------- | 
| «Сохрани как конспект по физике: закон Ома гласит...» |	Создаст конспект и предложит сохранить. |	
| «Напомни завтра в 19:00 подготовиться к экзамену» |	Создаст событие в календаре. |	
| «Что у меня запланировано на завтра?» |	Покажет ближайшие события. |	
| «Перескажи кратко мой последний конспект» |	Сделает краткую выжимку. |	

**Важно**: Перед сохранением или созданием напоминания бот обязательно спросит подтверждение — ничего не произойдёт без вашего согласия.

**Что делать, если бот не отвечает?** <br><br>
Проверьте подключение к интернету или напишите через пару минут.
